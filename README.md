# AI Placement Coach — HACKATHON-2026

## 🎯 Project in One Line
**AI Placement Coach is a student-first placement preparation platform that helps students practice, measure their performance, identify weak areas, and decide what to prepare next.**

---

## 👨‍🎓 Demo Story — From a Student's Perspective

Imagine I am a 3rd/4th-year engineering student preparing for campus placements.

### The problem I face
- I use different websites for aptitude, coding, DBMS and interview preparation.
- I practice questions, but I don't clearly know my weak topics.
- I waste time deciding what to study next.
- Interview practice is difficult to do consistently.
- Before placements, I need a simple view of whether I am actually improving.

### What I want
> **"I don't need just more questions. I need direction."**

### What AI Placement Coach gives me
**Practice → Score → Analyze → Improve → Prepare**

---

# 🚀 What the Demo Shows

## 1. Student Dashboard
The student starts from one place and can see:
- Placement preparation progress
- Practice performance
- Accuracy
- Skill/readiness information
- Areas that need attention

**Demo line:**  
> "As a student, this dashboard gives me a quick picture of where I stand."

---

## 2. Practice Zone

Students can choose different preparation areas:

| Area | Student Goal |
|---|---|
| 🧮 Aptitude | Improve quantitative and reasoning skills |
| 💻 DSA | Practice coding and data-structure concepts |
| 🗄️ DBMS | Prepare for database technical rounds |
| ☕ OOP / Java | Strengthen programming and OOP fundamentals |

The student answers questions and receives immediate feedback.

**Demo line:**  
> "Instead of searching for questions across multiple platforms, I can practice important placement topics here."

---

## 3. Performance Tracking

After practice, the platform helps the student understand:
- Score
- Accuracy
- Progress
- Topic performance
- Improvement areas

**Demo line:**  
> "The important part is not only my score. It is understanding why my score is low and what I should practice next."

---

## 4. Weak-Area Identification

The student can use performance information to identify topics that require more attention.

Example:

**Student performance**
- Aptitude → Strong
- DBMS → Good
- OOP / Java → Average
- DSA → Needs improvement

**Student decision**
> "I should spend more time on DSA instead of randomly practicing everything."

---

## 5. Interview Coach

The platform provides practice for:
- Java questions
- DSA questions
- HR/interview-style questions

The student can practice answering questions and use the feedback as preparation.

### Important Demo Note
The current hackathon version uses **rule-based demo interview responses**. It should be presented as an **AI-ready prototype**, not as a fully connected generative-AI system.

### Future version
A secure backend + LLM can provide:
- Dynamic questions
- Follow-up questions
- Personalized feedback
- Interview scoring
- Role-specific interview simulations

# 🎬 Recommended Live Demo Flow

Use this order during the presentation:

### Step 1 — Start with the problem
Say:

> "As students, we use many different resources for placements, but the biggest problem is not finding questions. The biggest problem is knowing what to prepare next."

### Step 2 — Open the Dashboard
Show the student's overall preparation view.

Say:

> "This is our student dashboard. It gives me a quick view of my placement preparation."

### Step 3 — Open Practice
Choose one topic such as **Aptitude** or **DBMS**.

Say:

> "Now I will practice a placement-oriented question set."

### Step 4 — Answer Questions
Answer several questions intentionally, including a few incorrect answers.

Say:

> "The platform immediately records my performance, so I don't have to manually track it."

### Step 5 — Show Performance
Show score/accuracy/progress.

Say:

> "Now I can see how I performed instead of just knowing whether an individual answer was correct."

### Step 6 — Show Weak Area
Point to the weaker topic.

Say:

> "This is where the platform becomes useful. It helps me understand where I should spend my preparation time."

### Step 7 — Open Interview Coach
Demonstrate one Java/DSA/HR question.

Say:

> "After technical preparation, I can also practice interview questions from the same platform."

### Step 8 — Finish With the Vision
Say:

> "Our vision is to turn this from a preparation website into a personal placement coach that understands a student's performance and continuously recommends the next best step."
