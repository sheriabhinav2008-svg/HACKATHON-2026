# AI Placement Coach — HACKATHON-2026

A responsive browser-based placement preparation platform.

Features:
- Aptitude, DSA, DBMS and OOP practice
- Instant answer feedback
- Score and accuracy tracking with localStorage
- Java, DSA and HR interview coach
- Responsive dashboard
- No backend required for the demo

Run:
Open index.html in a modern browser.

For production, connect the interview coach to an LLM through a secure backend. Never expose API keys in frontend code.
